# Frontend Projects

This repository contains frontend projects developed to practice web
development, user interface design, and building interactive web
applications.

## Projects

### 1. Music Learning Platform

An online platform designed to help users study piano theory, with YouTube
video links provided for different theory topics as additional learning
resources.

### 2. Smart Task & Schedule Manager

A task and schedule management application that allows users to create and
schedule tasks, mark tasks as completed, search for specific tasks, and
repeat previous tasks.

## Technologies Used

- HTML
- CSS

## Purpose

These projects were developed to practice frontend web development and
apply HTML and CSS to create practical and user-focused web applications.
