# Smart Task & Schedule Manager

## Description

The Smart Task & Schedule Manager is a task management application designed
to help users organize and keep track of their tasks and schedules.

## Features

- Create tasks
- Schedule tasks
- Mark tasks as completed
- Search for specific tasks
- Repeat previous tasks
- Keep completed tasks for tracking progress

## Technologies Used

- HTML
- CSS

## Purpose

This project was created to help users organize their schedules and manage
their tasks efficiently.
