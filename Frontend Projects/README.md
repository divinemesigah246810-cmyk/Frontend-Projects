# Music Learning Platform

## Description

The Music Learning Platform is an online platform designed to help users
study piano theory. It provides different music theory topics and includes
YouTube video links for users who want additional learning resources.

## Features

- Piano theory learning topics
- Access to learning resources
- YouTube video links for different theory topics
- Simple and accessible interface

## Technologies Used

- HTML
- CSS

## Purpose

This project was created to provide learners with an accessible platform
for studying piano theory and finding additional video resources.
